# `Windows First Aid`

Ein Erste-Hilfe-Kasten für Windows: ein Fenster mit Knöpfen, hinter denen die wichtigsten Reparatur-, Prüf- und Wartungsmittel von Windows stecken. Statt Befehle in der Eingabeaufforderung zu tippen, klickt man den passenden Knopf. Jeder Knopf hat eine Erklärung beim Draufzeigen, dazu gibt es ein eigenes Hilfe-Fenster.

**[Herunterladen (neueste Version)](https://github.com/kaesehobel79ch/windows-first-aid/releases/latest)**

Kostenlos (Freeware) von Käse_Hobel.

## Installieren

1. Unter „Herunterladen“ die Datei `Windows-First-Aid-<Version>.zip` laden.
2. ZIP entpacken.
3. `WindowsFirstAid-Setup.exe` starten und den Schritten folgen.

## Was drin ist

**Windows reparieren – der Reihe nach:** DISM CheckHealth, DISM ScanHealth, DISM RestoreHealth, SFC Scan

**Prüfen:** CHKDSK Scan, Ping-Test, Systeminformationen, Zuverlässigkeitsverlauf

**Schädlinge suchen:** Windows-Tool zum Entfernen bösartiger Software (MRT)

**Aufräumen:** DNS-Cache leeren, TEMP-Dateien löschen, SSD-TRIM ausführen, Datenträgerbereinigung

**Windows verwalten:** Geräte-Manager, Ereignisanzeige, Windows Update öffnen, Programme aktualisieren

**Windows neu installieren:** Media Creation Tool für Windows 11 und Windows 10

`Windows First Aid` ruft nur Werkzeuge auf, die in Windows bereits enthalten sind. Es wird nichts nachinstalliert und nichts verändert, was nicht auch von Hand über die Eingabeaufforderung möglich wäre. Für viele Werkzeuge fragt Windows nach Administratorrechten; ohne Zustimmung passiert nichts.

## Voraussetzungen

- Windows 10 oder Windows 11 (64 Bit)

Das Programm ist nicht digital signiert. Beim ersten Start kann sich deshalb der Windows-Schutz SmartScreen oder ein Virenscanner melden. Das ist ein Fehlalarm.
